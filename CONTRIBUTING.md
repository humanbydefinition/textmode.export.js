# Contributing to `textmode.export.js`

Thank you for helping improve `textmode.export.js`.

Start with the shared [code contribution guide](https://code.textmode.art/docs/contributing/code) for repository
routing, setup, workflow, documentation, testing, asset, and review expectations.

## Quick start

```bash
npm ci
npm run check
```

Create a focused branch from `dev` and open the pull request against `dev`. Discuss features, public API changes,
architecture, formats, packaging, browser support, or bundled assets in an issue before implementation.

Add or update tests, API documentation, and examples when behavior changes. Exercise affected export formats in a real
browser and include screenshots or recordings for visual or overlay changes.

Read the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately by following
[SECURITY.md](SECURITY.md), not through a public issue.

Need help? [Open an issue](https://github.com/humanbydefinition/textmode.export.js/issues), read the
[export guide](https://code.textmode.art/docs/exporting) or [API reference](https://code.textmode.art/api/textmode.export.js/),
or [join Discord](https://discord.gg/sjrw8QXNks).
